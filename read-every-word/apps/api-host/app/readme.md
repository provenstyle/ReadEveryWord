# api-host

Azure Function Host for `api`. This is the Nx project; its Terraform and deploy
scripts are siblings one level up:

```
apps/api-host/
├── app/         <- here
├── cicd/        <- init/plan/apply/destroy/validate/outputs, functionPush
└── terraform/   <- function app, table storage
```

The build bundles every `@read-every-word/*` library into a single ESM
`dist/main.js` and leaves npm packages external, so `dist` is a self contained
function app: `main.js`, `host.json`, and a generated `package.json` listing
only the real runtime dependencies. That is what runs locally and what ships.

## Running locally

```sh
# from the mono repo root
npx nx deploy-manifest api-host     # build, then write dist/package.json
cd apps/api-host/app/dist
npm install --omit=dev
func start --port 7074
```

Note `func start` runs from `dist`, not the project root, and takes no
`--typescript` flag: the artifact is already JavaScript.

`dist/package.json` is generated by `scripts/generate-deploy-manifest.mjs`,
which derives the dependency list from the specifiers `main.js` still imports.
Adding a dependency anywhere under `packages/` therefore shows up in the
deployed manifest automatically rather than as a cold start crash.

### Required settings

`fromEnv()` runs at module load and throws on anything missing, so all six of
these must be present or the app will not start:

`TABLE_STORAGE_CONNECTION_STRING`, `OPEN_ID_JWKS_URI`, `OPEN_ID_AUDIENCE`,
`OPEN_ID_ISSUER`, `OPEN_ID_DOMAIN`, `OPEN_ID_CLIENT_ID`.

Timer triggers need `AzureWebJobsStorage` for their singleton lock; locally
that means running azurite.

### Keep warm

Optional, off unless `KEEP_WARM=true`. Registers a once a minute timer that
makes a real http request to this app's own `healthCheck.get`, which is what
keeps a consumption plan instance warm — a timer firing on its own never
exercises the http path. Set `KEEP_WARM_URL` to override the target, which
local runs need since `WEBSITE_HOSTNAME` is only set in Azure:

```sh
KEEP_WARM=true KEEP_WARM_URL=http://localhost:7074 func start --port 7074
```

Each firing should log a `keep_warm_timer` invocation *and* a separate inbound
`Functions.trpc` invocation. One without the other means it stopped going over
the wire.
